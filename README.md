# TODO Планировщик задач

Веб-приложение на Go для ведения списка задач. Позволяет добавлять, редактировать, удалять задачи и настраивать их повторение. Данные хранятся в SQLite. Фронтенд уже готов — нужно только запустить сервер.

## Задания со звёздочкой

- Порт через переменную окружения `TODO_PORT`
- Путь к БД через переменную окружения `TODO_DBFILE`
- Полная поддержка правил повторения: `d`, `y`, `w`, `m`
- Поиск задач по тексту и дате (`/api/tasks?search=...`)
- Аутентификация по паролю через JWT (`TODO_PASSWORD`)
- Dockerfile для сборки и запуска в контейнере

## Как запустить локально

**1. Установите зависимости:**

```bash
go mod download
```

**2. Запустите сервер:**

```bash
go run .
```

**3. Откройте в браузере:** `http://localhost:7540`

---

По умолчанию сервер слушает порт `7540` и создаёт файл `scheduler.db` в текущей папке.

Если нужно изменить настройки — используйте переменные окружения:

```bash
# Пример с другим портом, паролем и путём к БД
TODO_PORT=8080 TODO_DBFILE=./mydb.db TODO_PASSWORD=secret go run .
```

| Переменная       | По умолчанию   | Описание                                              |
|------------------|----------------|-------------------------------------------------------|
| `TODO_PORT`      | `7540`         | Порт сервера                                          |
| `TODO_DBFILE`    | `scheduler.db` | Путь к файлу базы данных                              |
| `TODO_PASSWORD`  | _(пусто)_      | Пароль для входа. Если задан — включается авторизация |

> Если задан `TODO_PASSWORD`, при открытии сайта появится страница входа `http://localhost:7540/login.html`

## Как запустить тесты

Сначала запустите сервер (см. выше), затем в отдельном терминале:

```bash
go test ./tests
```

Настройки тестов находятся в файле `tests/settings.go`:

| Переменная     | Текущее значение | Что означает                                                        |
|----------------|------------------|---------------------------------------------------------------------|
| `Port`         | `7540`           | Должен совпадать с портом запущенного сервера                       |
| `DBFile`       | `../scheduler.db`| Путь к файлу БД относительно папки `tests`                         |
| `FullNextDate` | `true`           | `true` — тестировать правила `w` и `m`, `false` — только `d` и `y` |
| `Search`       | `true`           | `true` — тестировать поиск задач                                    |
| `Token`        | _(JWT строка)_   | Нужен только если задан `TODO_PASSWORD`. Берётся из куки `token` после входа на `/login.html` |

Запуск отдельных тестов по шагам:

```bash
go test -run ^TestApp$ ./tests       # шаг 1: файл-сервер
go test -run ^TestDB$ ./tests        # шаг 2: база данных
go test -run ^TestNextDate$ ./tests  # шаг 3: правила повторения
go test -run ^TestAddTask$ ./tests   # шаг 4: добавление задачи
go test -run ^TestTasks$ ./tests     # шаг 5: список задач
go test -run ^TestTask$ ./tests      # шаг 6: получение задачи по id
go test -run ^TestEditTask$ ./tests  # шаг 6: редактирование задачи
go test -run ^TestDone$ ./tests      # шаг 7: отметка о выполнении
go test -run ^TestDelTask$ ./tests   # шаг 7: удаление задачи
```

## Запуск через Docker

**1. Соберите образ:**

```bash
docker build -t todo-scheduler .
```

**2. Создайте папку для базы данных на хосте:**

```bash
mkdir -p ~/scheduler-data
```

**3. Запустите контейнер:**

```bash
docker run -d \
  -p 7540:7540 \
  -v ~/scheduler-data:/data \
  -e TODO_PASSWORD=secret \
  todo-scheduler
```

**4. Откройте в браузере:** `http://localhost:7540`

База данных сохраняется в `~/scheduler-data/scheduler.db` на вашем компьютере — при перезапуске контейнера данные не потеряются.
